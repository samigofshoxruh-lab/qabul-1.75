# Обновление Qabul, часть 2: админы платформы и обновление базы

## Почему сайт работает криво
Новый сайт уже ждёт новые таблицы и поля, а в вашей базе Supabase их ещё нет. Пока база не обновлена, часть экранов (оплаты, заявки, уроки, анкета, поддержка) будет показывать ошибки. Это лечится одним действием ниже.

## Шаг 1. Обновить базу (самый простой способ, без терминала)
1. Откройте supabase.com, зайдите в свой проект.
2. Слева выберите **SQL Editor**, затем **New query**.
3. Откройте файл `ОБНОВЛЕНИЕ_БАЗЫ.sql` из архива блокнотом, выделите всё (Ctrl+A), скопируйте и вставьте в окно запроса.
4. Нажмите **Run**. Должно появиться «Success». В разделе Messages будут строки «Применено …» или «Пропускаю … уже применено».
5. Если Supabase спросит про «destructive operations», нажмите **Run this query**: скрипт ничего не удаляет, он только добавляет таблицы и поля.

Скрипт можно запускать повторно, ничего не сломается: что уже применено, он пропускает. Данные не теряются, старые суммы «оплачено» станут одним платежом в истории.

Проверка: вставьте в новом запросе и нажмите Run:

    select version from supabase_migrations.schema_migrations order by version desc limit 5;

Должны быть версии 20261113000000, 20261114000000, 20261114100000, 20261114200000, 20261115000000.

Если вы всё же обновляете через терминал: `npx supabase login`, затем `npx supabase link --project-ref ВАШ_КОД_ПРОЕКТА` (код в адресе проекта в Supabase), затем `npx supabase db push`. Если запускали скрипт выше, `db push` напишет, что менять нечего.

## Шаг 2. Выложить функции
В терминале в папке проекта:

    npx supabase functions deploy platform channels lesson-notify --use-api
    npx supabase functions deploy support-notify --use-api --no-verify-jwt

Функция `platform` обязательна: без неё не заработают админы и права.

## Шаг 3. Выложить сайт

    git add .
    git commit -m "Админы платформы, права, обновление базы"
    git push

Через 1–2 минуты откройте сайт и обновите страницу (Ctrl+F5).

## Что нового: админы платформы
В админке появился раздел **Админы** (виден только тем, у кого есть право управлять админами, то есть вам).
- **Добавить админа:** email, пароль, роль. Роли: «Главный админ» (все права), «Менеджер» (компании, сроки, пользователи, поддержка), «Поддержка» (только чат) и «Свои права» (галочки вручную).
- **Права выдаёте вы лично:** Компании, Сроки доступа, Пользователи компаний, Поддержка, Админы платформы. Можно менять в любой момент и нажать «Сохранить права».
- Без права кнопка не показывается, а сервер всё равно отклонит действие.
- **Отключить** доступ галочкой, **сменить пароль** и **удалить** админа.
- Внизу журнал: кто, кому и что выдавал.
- Защита: нельзя отключить или удалить себя, нельзя остаться без админа, который управляет админами.
- Все, кто были админами до обновления, остаются главными админами со всеми правами.

## Telegram-уведомление в поддержку (по желанию)
1. В @BotFather создайте бота, скопируйте токен. Напишите своему боту любое сообщение.
2. Откройте `https://api.telegram.org/botТОКЕН/getUpdates` и найдите `"chat":{"id":ЧИСЛО`.
3. Выполните:

        npx supabase secrets set TELEGRAM_ADMIN_BOT_TOKEN=ТОКЕН TELEGRAM_ADMIN_CHAT_ID=ЧИСЛО SITE_URL=https://samigofshoxruh-lab.github.io/qabul
