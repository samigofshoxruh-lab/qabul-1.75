# Обновление Qabul

В архиве только то, что изменилось, каждый файл целиком. Папки совпадают с вашим проектом.

## Что добавлено
- Оплата: история платежей, частичные платежи, скидки, способы (наличные, карта, Payme, Click, перевод), «Напомнить о долге», отчёт за месяц с графиком и CSV. Payme и Click это пометка для бухгалтерии, подключения к ним нет.
- Аккаунт: кнопка «Аккаунт» (почта, смена пароля с текущим паролем, выход), «Выйти» с вопросом. Работает и у владельцев, и у админов платформы.
- Команда: галочки «Видит оплаты» и «Правит анкету» для каждого администратора.
- Заявки: фильтры (канал, ответственный, даты), вкладка «Мои заявки», «Вернуться к клиенту» с пометкой «просрочено», теги и источник, статистика по источникам, массовые действия, звук и уведомление о новой заявке.
- Уроки: неделя-календарь, повторяющиеся уроки, группы, «преподаватель» и «кабинет», отмена и перенос с сообщением ученикам через бота.
- Вопросы: ветвление, статистика «где бросают», рабочее время, русский и узбекский, проверка ответов (+998, возраст, число, почта).
- Поддержка: уведомление главному админу в Telegram, вложения, статус «открыто/решено», быстрые шаблоны ответов.
- Каналы: настоящие логотипы, тестовое сообщение с подсказкой, что не работает, плашка про Instagram.

## Как обновить
1. Распакуйте архив в папку проекта поверх старых файлов.
2. В терминале в папке проекта:

        npx supabase db push --remote
        npx supabase functions deploy channels lesson-notify --use-api
        npx supabase functions deploy support-notify --use-api --no-verify-jwt
        git add .
        git commit -m "Оплата, заявки, уроки, анкета, поддержка, аккаунт"
        git push

Сайт на GitHub Pages обновится сам после `git push`. Новые пакеты ставить не нужно.

## Telegram для главного админа (по желанию)
Без этого всё работает, просто в Telegram ничего не придёт.
1. В @BotFather создайте нового бота, скопируйте токен.
2. Напишите своему боту любое сообщение.
3. Откройте в браузере `https://api.telegram.org/botТОКЕН/getUpdates` и найдите `"chat":{"id":ЧИСЛО`. Это ваш chat id.
4. Выполните:

        npx supabase secrets set TELEGRAM_ADMIN_BOT_TOKEN=ТОКЕН TELEGRAM_ADMIN_CHAT_ID=ЧИСЛО SITE_URL=https://samigofshoxruh-lab.github.io/qabul

`CRON_SECRET` и Vault заново задавать не нужно, они уже есть.

## Важно знать
- Миграции работают поверх ваших данных. Старые суммы «оплачено» станут одним платежом «Перенесено из прежних данных».
- Администраторам по умолчанию оплаты видны, анкету они менять не могут. Владелец меняет это галочками в «Команде».
- Если администратору запретить оплаты, база закроет ему платежи и раздел «Оплаты». Цены в карточках учеников скрываются на сайте.
- Вложения в поддержке хранятся в приватном хранилище `support-attachments`, до 5 МБ, картинки и PDF.
- Не сделано: кнопка «Подключить Instagram» без токенов. Она возможна только после одобрения приложения Meta, сейчас на плашке так и написано. Подключение Payme и Click тоже не делалось.
- Проверено: тесты базы (60 из 60), сборка сайта, проверка типов, Edge Functions. Сквозные тесты с Telegram и Instagram (`test:e2e`) у меня не запускались, нужен PostgREST.
