# Как выложить проект на новый GitHub и запустить

Ниже полный порядок. Команды для Mac (Терминал). В Windows используйте Командную строку (cmd), а не PowerShell.

## 0. Что нужно
- Аккаунт GitHub и аккаунт Supabase.
- Node.js 20 или новее (https://nodejs.org).
- Git (на Mac спросит установить при первой команде `git`) или программа GitHub Desktop.

## 1. Создайте репозиторий на GitHub
1. github.com → кнопка New repository.
2. Название: `qabul`. Выберите Public (бесплатный GitHub Pages работает только с открытым репозиторием).
3. Ничего не отмечайте (без README, без .gitignore). Нажмите Create repository.

## 2. Загрузите код
Распакуйте архив `qabul-fixed.zip`. Откройте Терминал в этой папке и выполните, заменив ЛОГИН на ваш логин GitHub:

    git init
    git add .
    git commit -m "Qabul: первая загрузка"
    git branch -M main
    git remote add origin https://github.com/ЛОГИН/qabul.git
    git push -u origin main

GitHub попросит вход. Вместо пароля вставьте Personal Access Token: GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate, права `repo` и `workflow`. Проще: GitHub Desktop → File → Add Local Repository → Publish repository.

Папка `.github` скрыта в Finder (показать скрытые файлы: Cmd+Shift+.). Загрузка через браузер может её пропустить, поэтому используйте команды выше.

## 3. Supabase
У вас уже есть проект Supabase, он остаётся прежним. База и каналы сохранятся.

    npm install
    npx supabase login
    npx supabase link --project-ref ВАШ_PROJECT_REF
    npx supabase db push --remote
    npx supabase functions deploy --use-api
    npx supabase functions deploy webhook --use-api --no-verify-jwt

`PROJECT_REF` лежит в Supabase → Project Settings → General.

Секреты `TOKEN_ENCRYPTION_KEY` и `CRON_SECRET` НЕ задавайте заново, если проект уже работал. Новый `TOKEN_ENCRYPTION_KEY` сделает все сохранённые токены нечитаемыми, и каналы придётся подключать заново. Если проект новый:

    npx supabase secrets set TOKEN_ENCRYPTION_KEY=любая_строка_от_32_символов CRON_SECRET=другая_строка_от_32_символов

Для нового проекта ещё выполните в SQL Editor:

    select vault.create_secret('https://ВАШ_PROJECT_REF.supabase.co/functions/v1', 'qabul_functions_url');
    select vault.create_secret('ТА_ЖЕ_СТРОКА_CRON_SECRET', 'qabul_cron_secret');

И назначьте главного админа (сначала создайте пользователя в Authentication → Users):

    insert into public.platform_admins (user_id)
    select id from auth.users where email = 'ВАШ_EMAIL';

## 4. Сайт на GitHub Pages
1. Репозиторий → Settings → Pages → Source: GitHub Actions.
2. Settings → Secrets and variables → Actions → вкладка Variables → New repository variable:
   - `VITE_SUPABASE_URL` = адрес проекта (Supabase → Project Settings → API)
   - `VITE_SUPABASE_PUBLISHABLE_KEY` = publishable key (начинается с `sb_publishable_`)
3. Вкладка Actions → Deploy site → Run workflow (или сделайте любой push в main).
4. Адрес сайта: Settings → Pages. Обычно `https://ЛОГИН.github.io/qabul/`.

Если логин или название репозитория другие, замените `site_url` в `supabase/config.toml` на свой адрес и выполните `npx supabase config push`.

## 5. Проверка
1. Войдите на сайт. Каналы → Telegram → «Проверить».
2. Напишите боту. Заявка появится на сайте.
3. Instagram: нажмите «Настройка webhook» и перенесите Callback URL и Verify token в Meta → Instagram → Webhooks. Включите подписку на поле `messages`.
4. Добавьте второй аккаунт в Meta → App Roles → Instagram Tester и примите приглашение в Instagram (Настройки → Приложения и сайты → Приглашения тестировщика). Пишите с этого аккаунта.
5. В Instagram: Настройки → Сообщения → разрешить доступ к сообщениям (аккаунт должен быть профессиональным).
6. Если не отвечает: Supabase → Edge Functions → webhook → Logs, ищите `[diag]`.

## Что изменено в этой версии (оплата)
- Новая миграция `supabase/migrations/20261113000000_payments_history.sql`: таблица `payments` (история платежей), поле `discount` (скидка) у ученика, способы оплаты: наличные, карта, Payme, Click, перевод, другое.
- Старые суммы «оплачено» перенесены в историю одним платежом «Перенесено из прежних данных». Ничего не теряется.
- `src/pages/PaymentsPage.tsx`: вкладки «Долги», «История платежей», «Отчёт за месяц». Частичные платежи, кнопка «Напомнить о долге» (пишет клиенту в его канал), отчёт с графиком и CSV.
- `src/pages/LessonsPage.tsx`: поле «Скидка» у ученика.
- Payme и Click не подключены: это пометка способа для бухгалтерии компании.

## Как обновить уже работающий проект
    npm install
    npx supabase db push --remote
    git add .
    git commit -m "Оплата: история платежей, скидки, отчёт"
    git push

Edge Functions заново выкладывать не нужно: они не менялись. Сайт на GitHub Pages обновится сам после push.
